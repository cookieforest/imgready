Why batch matters

Most "convert image" workflows are either casual (one or two photos) or industrial (an automated pipeline behind a CMS). The middle ground — somebody who needs to convert 50 to 500 files once or twice a month and doesn't want to write a script — is poorly served by every other free tool. Either there's a 5-file or 5-MB cap, or the tool requires an account, or it uploads everything to a server, or it costs money. imgready handles batch in your browser without any of those friction points.

What you can do in a single batch

  • Mix input formats. A folder containing JPGs, PNGs, HEICs and TIFFs is processed end-to-end in one click. Each file is decoded with the right pipeline (libheif for HEIC, the TIFF parser for TIFF, the canvas for everything else) and re-encoded to your chosen target.
  • Pick a single output format. WebP, AVIF, JPG, PNG, or GIF — every file in the batch encodes to your chosen target.
  • Apply a resize and a crop ratio across the whole batch. Set "Longest side: 1600" once, and every input file gets resized to that dimension while preserving its aspect ratio (or cropped first if you also pick a ratio).
  • Use a per-platform preset. Pick Instagram Post or YouTube Thumbnail in Settings, and every file is resized and cropped to that platform's specs.

Batch limits and what to expect on memory

Browsers are surprisingly capable but they're not unlimited. imgready has a soft cap at 200 files per batch — drop more and you'll see a confirmation prompt. The actual constraint is your browser's memory budget; most laptops handle 200 phone-sized photos without trouble, but on mobile or older devices it's safer to do batches of 50–100. If a batch fails midway, refresh and split it. Each file is processed sequentially, so a slow output (AVIF) doesn't slow the rest down — it just makes the total batch take longer.

Tips for fast batch conversion

  • Resize before converting. An unresized 12-MP photo encodes in 8x the time of a resized one.
  • Don't use AVIF unless you need it. AVIF encodes 5–10x slower than WebP.
  • Pick one format per batch. If you need multiple output formats, run the batch separately for each — total time scales linearly with format count anyway.
  • Close other heavy tabs. Browser memory is shared; a 32-tab Chrome session leaves little for image encoding.

Batch is also where the privacy story matters most

Cloud-based converters typically have a per-file size cap and a per-account daily quota. To get past those, you'd need a paid plan and you'd be uploading hundreds of personal photos to a third party. imgready does it all in your browser — there's no server to hit, so there's no quota and no upload. For sensitive content (medical scans, scanned ID, financial documents), this is the only practical choice.

Frequently asked questions

How many files can I batch process?

Soft cap is 200 files; drop more and you'll see a confirmation prompt. Practical limit depends on your device's memory — most laptops handle 200 phone photos comfortably, mobile devices may need smaller batches.

Can I mix formats in one batch?

Yes. JPGs, PNGs, HEICs, TIFFs, WebPs, AVIFs, GIFs, BMPs, and SVGs can all be in the same batch. Each file is decoded with its appropriate decoder.

Can I generate multiple output formats at once?

Pick one format per batch. If you need multiple output formats (e.g. WebP + JPG fallbacks for a <picture> element), run the batch separately for each format.

How does batch handle errors?

If one file fails to decode or encode, imgready marks it with an inline error message and continues with the rest. The other files are not affected.

Do batch operations run in parallel?

imgready processes files sequentially. This trades raw throughput for stable memory use — running everything in parallel is faster but easily OOMs the browser tab.

Will batch work on a phone?

Yes, but with smaller batches. iOS Safari is conservative with memory; we recommend 30–50 files per batch on phones rather than the desktop default of 200.
