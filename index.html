What imgready does

Compress, convert and resize images with the same WebAssembly encoders professional tools use — WebP, AVIF, JPG, PNG and GIF on the way out; HEIC, HEIF, TIFF, BMP, SVG on the way in. Batch any number of files. Output multiple formats in a single pass. Drop a folder. Strip EXIF. Use a platform preset. Live-edit quality with the fullscreen compare editor.

Encoding runs in your browser. The thinking behind it goes deeper into what that means for speed and file-size limits.

Common use cases

imgready is designed for the everyday image work that doesn't deserve a separate app. A few of the things it gets used for:

  • iPhone photos for Windows colleagues. Drop a HEIC, get a JPG back. No app install, no email back-and-forth about "why won't this open".
  • Hero images for blog posts. Resize a 5 MB phone photo to 1600 px wide WebP under 200 KB. Pages load faster, Lighthouse score climbs, no CDN cost.
  • Shopify or Etsy product photography. Drop a folder of 50 photos, set a platform preset, hit Process All, download a single ZIP. Aspect ratios stay correct.
  • EXIF stripping before sharing. Phone photos carry GPS coordinates by default. imgready strips them invisibly before you post — no extra step, no extra tool.

How it actually works

When you drop a file, imgready runs the same WebAssembly encoders Squoosh ships — but locally, on your machine. HEIC and HEIF decode through libheif (the C++ library Apple uses). WebP and AVIF encode with jsquash, Google's reference encoders ported to WebAssembly. PNG compression uses OxiPNG and UPNG for size, the browser's canvas for lossless. Resizing and cropping run on the HTML5 canvas API. None of this requires a server because none of it needs one — your machine has the compute.

Frequently asked

Are my images uploaded?

No. Encoding runs in your browser. If you'd like to see for yourself, open DevTools and watch the Network tab while you drop a file — no requests carry image data.

What's the difference between WebP and AVIF?

Both are modern formats designed to replace JPEG. WebP offers excellent compression and is supported by every major browser since 2020. AVIF compresses tighter (up to 50% vs JPEG) but encodes more slowly. imgready uses WebAssembly encoders for both so every device gets identical output regardless of browser. The WebP vs PNG vs JPG guide covers when to pick which.

How big a batch can I drop in?

The soft cap is 200 files, with a confirmation prompt above that. Practically, browsers handle a few hundred phone-sized photos comfortably on a recent laptop. On older devices or phones, smaller batches (50–100) are safer. There's no hard limit because there's no server queue — only your computer's RAM.

Is there a file-size cap?

No. Drop a 100 MB TIFF if you have one. imgready has no caps because there's no server to bill for storage. The only constraint is your browser's available memory, which on a typical machine is several gigabytes — enough for any normal photo or scan.

Can I resize and compress at the same time?

Yes. Open Settings, pick a platform preset (Instagram, YouTube, Twitter/X, email-safe) or type a longest-side dimension, then choose your output format and hit Process. Crop ratios and EXIF stripping are in the same panel. The resize and compression both happen in the same pass — no double-encoding.

What if the file fails to convert?

Two common reasons: the file is corrupted (not actually an image despite the extension), or the file uses a TIFF compression imgready doesn't support (anything beyond uncompressed, LZW, PackBits). When this happens you'll see a card-level "Couldn't read this file" error with a Retry button. If retrying doesn't help, opening the file in any image editor and re-saving it usually fixes the issue.

Does imgready work on iPhone or iPad?

Yes — imgready works in mobile Safari and iOS Chrome. iOS Safari has a known bug in its native WebP encoder, so on iOS imgready always uses the WebAssembly encoder for consistent output. AVIF encoding on phones is noticeably slower and warmer than on desktop; for batch work on phones we recommend smaller groups (30–50 files at a time).

Is imgready really free?

Yes — completely, with no caps. The site runs on Google AdSense ads (your image data is never sent to ad partners) and voluntary Ko-fi contributions. There's also a paid SDK for developers who want to embed imgready into their own products without the attribution badge — that's on the developers page.
