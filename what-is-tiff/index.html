What is a TIFF file? The professional image format explained

TIFF (Tagged Image File Format) is the gold-standard format for professional photography, document scanning, and print preparation. Created in 1986, TIFF remains the archival format of choice because it's lossless — every pixel of image data is preserved perfectly, with no quality loss. TIFF files are much larger than JPEG or PNG, but that size is the trade-off for absolute fidelity. Here's what TIFF is, why professionals use it, when to convert to other formats, and how to work with TIFF files.

Quick answer

TIFF stands for Tagged Image File Format. It's a lossless format that preserves every pixel of image data perfectly. TIFF files are huge — a 4 MB photo as JPEG might be 30 MB as TIFF — but they're the industry standard for archival, professional photography, and print preparation. For web use and sharing, convert TIFF to JPEG or PNG. For editing and long-term storage, TIFF is the right choice.

The core principle: TIFF trades file size for quality. If you need pixel-perfect image data that won't degrade through edits and re-saves, TIFF is uncompromising. If you need to share files over the internet, TIFF is impractical.

History and origin

TIFF was created in 1986 by Aldus Corporation (now Adobe) as a flexible, lossless format for document scanning and professional imaging. Before TIFF, there was no widely-accepted standard for high-quality image archival. TIFF filled that gap and became the gold standard for photographers, archivists, and print professionals. In 2026, decades later, TIFF remains the default format for scanner output and professional workflows.

Why it persists

TIFF's longevity is remarkable because it solved a real problem: preserving image quality over time. Museums, libraries, government archives, and professional photographers still use TIFF because the format is stable, well-documented, and truly lossless. A TIFF file from 1995 can be opened and edited in 2026 without any quality loss.

How TIFF stores image data

TIFF can store image data in several ways. The most common for photography is uncompressed RGB or CMYK at 8-bit or 16-bit per channel. An uncompressed RGB TIFF of a 4000x3000 pixel photograph would be roughly 36 MB (4000 × 3000 × 3 bytes). TIFF can also use lossless compression like LZW or ZIP to reduce size while maintaining perfect quality — a 36 MB uncompressed TIFF might compress to 15–20 MB with LZW, still vastly larger than a 2–5 MB JPEG.

Why not just use JPEG compression?

TIFF is deliberately designed to avoid JPEG's lossy compression. Lossy compression discards image data to achieve smaller files. TIFF rejects that trade-off. Every time you save a JPEG, quality is lost. Every time you save a TIFF, quality is preserved. For photographers, editors, and archivists, this distinction is critical.

16-bit and 32-bit color depth

TIFF's greatest advantage over JPEG is support for 16-bit and 32-bit color depth. Standard digital images are 8-bit per channel (256 levels per color), which is adequate for most viewing. Professional photographers and retouchers work in 16-bit (65,536 levels per color) to preserve subtle tonal gradations and avoid banding in large areas of similar color. A 16-bit TIFF file can be edited and re-saved repeatedly without visible quality loss, even with aggressive adjustments.

JPEG only supports 8-bit. Once you save as JPEG, you lose the ability to work with 16-bit data. This is why professionals always edit in TIFF or PSD and export to JPEG only at the very end.

Multi-page TIFF files

TIFF can store multiple images in a single file. Document scanning produces multi-page TIFFs (one file = one scanned document with 10, 50, or 100 pages). This makes TIFF ideal for archival scanning and batch processing. Web browsers and most consumer software cannot handle multi-page TIFFs, so these files are strictly professional tools.

When to use TIFF

  • Professional photography workflows and editing
  • Long-term archival and storage
  • Document scanning and OCR preparation
  • Print preparation and pre-press work
  • Photographic retouching and color correction
  • Any workflow where image quality must be preserved through multiple edits
  • Museum, library, and government archival

When to convert to JPEG or PNG

  • Sharing photos via email or messaging
  • Web publishing and online galleries
  • Social media (Facebook, Instagram, etc.)
  • Cloud storage with bandwidth concerns
  • Client delivery where file size matters
  • Printing from consumer devices (most assume JPEG)
  • Any situation where the recipient doesn't need 16-bit data

TIFF vs JPEG: The trade-off

TIFF is objectively superior for professional work and archival. JPEG is practically superior for sharing and web use. A photographer's workflow typically looks like this:

  1. Capture RAW files from the camera
  2. Edit in 16-bit TIFF or PSD (lossless)
  3. Archive the edited TIFF for long-term storage
  4. Export final image as JPEG for client delivery or web

This workflow protects image quality at every stage. Exporting to JPEG directly from the camera or from an 8-bit source means quality is lost forever.

Opening and converting TIFF files

On Windows, the built-in Photos app can open TIFF files. On Mac, Preview handles TIFF natively. For editing, use Photoshop, GIMP (free), Capture One, or Lightroom. To convert TIFF to JPEG, PNG, or WebP for sharing, use a free online tool like imgready or command-line tools like ImageMagick and FFmpeg.

For archivists: TIFF is the recommended format for digitizing historical photographs and documents. The Library of Congress, National Archives, and UNESCO all recommend TIFF for digital preservation because of its stability and lossless nature.

Frequently asked questions

What is a TIFF file?

TIFF (Tagged Image File Format) is a lossless image format created in 1986 as the professional standard for high-quality photography, document scanning, and print preparation. TIFF files preserve every pixel of image data without compression loss, supporting 8-bit, 16-bit, and 32-bit color depth. This makes TIFF ideal for archival and professional work, but files are much larger than JPEG or PNG.

Why are TIFF files so large?

TIFF uses lossless compression (or no compression at all), meaning every pixel is stored with full detail. A 4000x3000 pixel photograph as TIFF with no compression would be roughly 36 MB (4000 × 3000 × 3 bytes for RGB). As JPEG, the same image might be 2-5 MB. TIFF's size is the trade-off for preserving absolute image fidelity, making it unsuitable for web use but essential for professional archives.

Can I open TIFF in Windows?

Windows 10 and 11 can open TIFF files with the built-in Photos app. Most image viewers, Photoshop, GIMP, and professional software support TIFF natively. However, web browsers cannot display TIFF directly — you must convert to JPG, PNG, or WebP to view online. For sharing TIFF files, recipients need compatible desktop software.

Is TIFF lossless?

Yes, TIFF is primarily used as a lossless format. It can store images with zero quality loss, preserving every pixel of detail from the original. TIFF can also use lossless compression (like LZW) to reduce file size while maintaining perfect image quality. This is the opposite of JPEG, which uses lossy compression and discards data to save space.

What's better: TIFF or JPG?

For professional and archival use, TIFF is better — it preserves absolute image quality and is the industry standard for photography, scanning, and print. For web use and everyday sharing, JPEG is better — it's much smaller, universally compatible, and perfectly adequate for most purposes. The choice depends on your workflow: TIFF for editing and archiving, JPEG for distribution.
