Quick answer

HEIC stands for High Efficiency Image Container. It's built on Apple's HEIF standard and uses H.265 video compression technology. HEIC files are about 50% smaller than JPEG at the same visual quality, but Windows 10 (and earlier), Android, and many apps don't support them natively. If you need to share HEIC photos with others or use them on non-Apple devices, convert them to JPEG or PNG.

The core problem: Apple invented HEIC for storage efficiency. It works great within the Apple ecosystem. But the rest of the world still uses JPEG, PNG, and WebP. That incompatibility gap is why HEIC remains frustrating in 2026.

What HEIC actually is

HEIC (High Efficiency Image Container) is a container format that wraps images compressed with the H.265 codec — the same codec used in modern video streaming. Apple adopted it in iOS 11 (2017) as the default format for all iPhone and iPad photos. The format can store multiple images, sequences, animated photos, depth maps, and metadata all in a single file.

HEIC vs HEIF: What's the difference?

HEIF (High Efficiency Image Format) is the broader standard. HEIC is Apple's specific implementation of HEIF using H.265 compression. For practical purposes, the terms are often used interchangeably when discussing Apple photos, though HEIF is technically the standard and HEIC is Apple's container.

Why is HEIC 50% smaller than JPEG?

HEIC uses H.265 video compression, which is dramatically more efficient than JPEG's DCT algorithm from 1992. H.265 analyzes image data in more sophisticated ways — it looks at larger blocks, uses better prediction models, and applies adaptive entropy coding. The result: a typical iPhone photo that's 4 MB as JPEG might be just 2 MB as HEIC with visually identical or superior quality.

For iPhone storage, this matters enormously. Users with limited capacity get more photos per gigabyte. Cloud backup bandwidth shrinks. But that efficiency advantage only works if you're staying in Apple's ecosystem.

Quality trade-off

HEIC's smaller file size doesn't come with quality loss — it actually preserves more detail at the same file size. Modern smartphones use HEIC's superior compression to capture photos with better quality while using less storage space.

Why Windows and Android can't open HEIC

H.265 and HEIF were patented technologies with significant licensing requirements. Microsoft and Google were slower to license and implement H.265 support in their platforms. Android phone manufacturers, which represent over 70% of the global smartphone market, don't use HEIC — they use JPEG. Windows had no built-in HEIC support until Windows 10 version 1803 (2018), and even then the support is incomplete and requires additional codec installation.

This incompatibility is less about technical capability and more about patent licensing, ecosystem preference, and the lack of industry-wide adoption. In 2026, while support has improved, HEIC remains an Apple ecosystem format.

How to open HEIC files on Windows

Windows 11 and Windows 10 (build 1803 and later) can open HEIC files if you install the free HEIC Image Extensions from the Microsoft Store. Search for "HEIC" in the Store and install the official extension. After installation, you can open HEIC files in the built-in Photos app and most modern image viewers.

For older Windows versions, or if the extension isn't working, the most reliable solution is to convert HEIC files to JPEG or PNG using a free online tool. This approach also works for apps that don't support HEIC at all.

Can I turn off HEIC on my iPhone?

Yes. Go to Settings > Camera > Formats and toggle the 'Most Compatible' option. This tells your iPhone to save all new photos as JPEG instead of HEIC. The change only applies to photos taken after the toggle — existing HEIC photos remain unchanged. You'll still be able to see and edit your HEIC photos, but new ones will be JPEG.

The trade-off: JPEG files are roughly twice as large as HEIC. If you're sharing frequently with non-Apple users, this is worth it. If you only share with other iPhone users, keep HEIC enabled for storage efficiency.

Is HEIC better than JPEG?

Technically, yes. HEIC provides superior compression, supports modern features like transparency and HDR, and delivers better quality at smaller file sizes. For photography and image archival, HEIC is objectively the better format. However, JPEG is more widely supported across all platforms, devices, and applications. So while HEIC is technically superior, JPEG remains more practical for sharing and collaboration.

When HEIC makes sense

  • Photos on iPhones and iPads (Apple's ecosystem)
  • Cloud backup to iCloud (HEIC support is built-in)
  • Photo libraries where storage is the primary concern
  • Internal archival where you control the viewing software

When JPEG is better

  • Sharing photos with mixed iOS and Android friends
  • Uploading to websites that may not support HEIC
  • Sending via email or messaging apps with older users
  • Working with Windows or Linux photo editing software

Frequently asked questions

What is HEIC?

HEIC (High Efficiency Image Container) is Apple's default photo format for iPhones and iPads since 2017. It's built on the HEIF standard and uses H.265 video compression to create image files that are approximately 50% smaller than equivalent JPEG files while maintaining superior image quality. HEIC supports both lossy and lossless compression, transparency, and multiple images per file.

Why can't Windows open HEIC files?

Windows didn't natively support HEIC until Windows 10 version 1803 (2018), and even then support is limited. Windows lacks built-in HEIC codecs, so older versions and many applications simply cannot open HEIC files. Android phones do not use HEIC, so the format was less critical for cross-platform compatibility. Today, Windows 11 has better HEIC support, but JPEG and PNG remain more universally compatible.

How do I open HEIC on PC?

On Windows 10 (build 1803+) or Windows 11, install the free HEIC Image Extensions from the Microsoft Store. For older Windows versions or if the extension doesn't work, convert your HEIC files to JPEG or PNG using a free online tool like imgready — it works entirely in your browser without uploading anything. Most desktop image viewers now support HEIC, but conversion is the most reliable solution for universal compatibility.

Can I turn off HEIC on iPhone?

Yes. Open Settings > Camera > Formats and toggle 'Most Compatible' to switch back to JPEG. Choosing 'Most Compatible' will save all new photos as JPEG instead of HEIC, making them easier to share with non-Apple devices. This is useful if you regularly share photos with Android users or Windows PCs, though it means larger file sizes. HEIC can remain enabled while using this setting.

Is HEIC better than JPG?

Yes, HEIC is technically superior to JPEG. HEIC files are approximately 50% smaller at the same visual quality, support modern features like transparency and HDR photography, and use more efficient compression algorithms. However, JPEG is more widely supported across all devices and platforms. For sharing and archiving, JPEG remains more practical. For iPhone storage, HEIC is the better choice.
