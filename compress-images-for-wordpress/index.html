Why WebP is essential for WordPress performance

WebP is 25–35% smaller than JPEG at equivalent quality, and is supported by 97% of modern browsers. A typical WordPress featured image that's 250 KB as JPEG becomes 150–180 KB as WebP — no visible difference, but instant LCP improvement.

The only downside? Older browsers (Safari on iOS, some old Firefox versions) don't support WebP. The solution is a <picture> tag that serves WebP to modern browsers and JPEG to everything else:

<picture><source srcset="image.webp" type="image/webp"><source srcset="image.jpg" type="image/jpeg"><img src="image.jpg" alt="..."></picture>

AVIF: the next frontier

AVIF is even smaller than WebP (50–60% of JPEG size), but browser support is still limited (no Safari, no iOS, Firefox only on desktop). If you want maximum compression, serve AVIF as a first option with WebP and JPEG fallbacks. Most WordPress plugins don't support AVIF yet, but services like Cloudinary can generate AVIF automatically.

Recommended image dimensions for WordPress

Hero / featured images: Aim for 1200px wide at 2x pixel density (2400px actual). After resizing and compressing, target 60–100 KB. This is large enough to display full-width on desktop and tablets, but small enough to load quickly.

Blog post thumbnails: 600px wide is ideal for grid layouts and archive pages. After compression, keep under 50 KB.

Body content images: 800–1000px wide is standard. Users can click to enlarge, but the embedded version should load instantly — target 100–150 KB.

Logos and graphics: These compress poorly as JPEG. Use PNG or SVG. If you use PNG, compress it with imgready's PNG optimizer to eliminate metadata and reduce file size by 30–40%.

Lazy loading: bonus performance win

After compressing images, enable lazy loading to defer off-screen images. Add loading="lazy" to every <img> tag:

<img src="image.webp" alt="..." loading="lazy" width="800" height="600">

This tells browsers to load only visible images, deferring below-the-fold images until the user scrolls. Combined with image compression, lazy loading can cut initial LCP in half.

Frequently asked questions

What image format is best for WordPress?

WebP is the best modern format for WordPress — it's 25–35% smaller than JPEG with better quality, and has near-universal browser support (97% of users). Always serve a JPEG fallback for older browsers. AVIF offers even better compression but limited support. Use PNG only for logos and graphics with transparency.

What size should images be for WordPress?

Hero images should be 1200px wide, blog thumbnails 600px, and post body images 800px wide. After compression, target 100 KB for heroes, 50 KB for thumbnails, and 150 KB for body images. Smaller files load faster and improve Core Web Vitals — Google's ranking factor.

Does image size affect WordPress SEO?

Yes, critically. Google measures Largest Contentful Paint (LCP), which is delayed by large uncompressed images. A slow LCP hurts rankings and increases bounce rate. Compress images to improve LCP, user experience, and SEO performance simultaneously.

How do I convert images to WebP in WordPress?

Use imgready's free WebP converter to convert before upload. Alternatively, WordPress plugins like Imagify or ShortPixel auto-convert on upload. For maximum control and smallest file sizes, convert with imgready first, then upload WebP with JPEG fallbacks using <picture> tags or plugin support.

What is Core Web Vitals and why do images matter?

Core Web Vitals are three Google metrics: Largest Contentful Paint (LCP), First Input Delay (FID), and Cumulative Layout Shift (CLS). Images are the #1 cause of slow LCP. Large uncompressed images delay rendering and harm rankings. Compress images to meet all three Core Web Vitals thresholds.

Can I use AVIF in WordPress?

AVIF compresses to 50–60% of JPEG size, making it excellent for WordPress, but support is limited (no Safari, no iOS). If you use AVIF, provide WebP and JPEG fallbacks via <picture> tags. Most WordPress plugins don't support AVIF yet — use Cloudinary or manually manage fallbacks.
