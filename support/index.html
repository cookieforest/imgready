Frequently asked questions

Does paying remove ads?

Not currently — ads are the primary funding mechanism. A contribution helps cover hosting and development time but doesn't change the ad experience.

Is imgready at risk of shutting down?

The running costs are low (static hosting plus CDN). As long as there's any traffic at all, it will stay online. Contributions help but aren't what keep the lights on.

Can I request features?

Yes — email hello@imgready.app or use the support form. Feature requests that help the most users get prioritised.

I found a bug or something isn't working — how do I report it?

The best way to report issues is via the imgready GitHub repository — open an issue describing what you were doing, which browser you're using, and what happened.

Can I request a new feature or format?

Yes — feature requests are welcome. Open a GitHub issue with the label feature request and describe the conversion or tool you'd like added. The most commonly requested formats and features rise to the top of the development queue.

How do I report a conversion quality issue or bug with a specific format?

Open a GitHub issue on the imgready repository with details: the original file format, what you were converting to, what the problem was, and your browser/OS. Attach a problematic sample image if possible (without sensitive data). This helps the developer reproduce and fix the issue quickly.
